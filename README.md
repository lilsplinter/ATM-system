# ATM System (C++)

*Deutsch: Konsolen-ATM-System in C++ mit Login, Einzahlung, Abhebung und Kontostand. Kundendaten werden in einer Datei gespeichert.*

A console ATM system written in C++. It lets one client log in and manage their account.

## Features
- [Login with account number and PIN]
- [Quick withdraw]
- [Normal withdraw]
- [Deposit]
- [Check balance]

## How to run
1. Open `ATMsystem.sln` in Visual Studio.
2. Press Run.

## Possible improvements
- Hash PINs instead of storing them in plain text
- Limit failed login attempts
- Split the code into separate files

## Skills practiced
C++, functions, structs, file handling, input validation
